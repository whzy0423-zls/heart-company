# 课堂管理稳定性与百炼音色统一设计

## 目标

在保留现有课堂、实时语音和历史数据的前提下，完成以下兼容迭代：

1. 连续新建课件时始终创建新记录，不继承或覆盖上一次课件。
2. 已下架课件可从后台“删除”，采用归档语义保留历史权益和学习数据。
3. 上传完成阶段允许媒体探测、首帧封面生成等耗时处理，客户端超时后可对账恢复。
4. 上传任务后台刷新不再反复切换骨架屏。
5. 课堂列表支持选择多条课件并原子批量发布。
6. 课程系列支持独立封面、比例配置，以及第一节课封面回退。
7. 小程序“老师课堂 / 最近更新”按时间混排系列与独立课件。
8. 新音色克隆统一使用阿里百炼 Qwen；旧 MiniMax 档案只保留迁移兼容，不再作为新建入口。

## 约束

- `main` 和 `test` 均为长期分支，本轮只在独立功能分支修改，`test` 不参与。
- 不覆盖主工作区中尚未提交的芯之力实时语音改动。
- 不移除既有 WebSocket 实时语音协议或 MiniMax 历史数据读取能力。
- 本地运行及验证不使用 Docker。

## 设计

### 连续新建课件

课堂编辑弹窗关闭时销毁编辑器实例；每次新建生成新的组件 key，并在保存、取消后清空父级编辑对象。这样表单状态、已创建记录缓存、元数据提交标记都会随组件一起释放，第二次保存仍走 Create。

### 下架删除

新增 `archived` 状态作为后台删除结果。无依赖的草稿仍可物理删除；`offline` 课件删除时更新为 `archived`。后台默认列表和所有公开查询排除归档记录，订单、权益、进度、媒体及 OSS 对象保持不变。

### 批量发布

新增显式路由 `POST /api/admin/classroom/contents/batch-publish`。请求最多 100 条，服务端去重、排序、逐条加锁并在单事务中执行与单条发布相同的并发版本、媒体就绪和系列状态校验；任一失败整体回滚。后台表格增加勾选与批量发布按钮。

### 上传稳定性

上传完成接口使用 180 秒客户端超时。服务端将媒体完成处理绑定到独立有界上下文，使请求连接取消后仍可完成成功或失败落库。客户端遇到超时不立即 abort，而是读取任务状态；`completing` 状态持续轮询并显示“媒体处理中”。

上传任务页面区分首次加载和静默刷新，轮询等待上一请求完成，使用序号丢弃旧响应；页面隐藏或没有非终态任务时暂停高频轮询。

### 系列封面

系列记录增加手动封面对象 key 和封面比例。后台系列编辑器复用现有封面上传交互，支持 16:9、9:16、1:1，默认 16:9。显示优先级为：手动封面、历史封面 URL、系列第一节已发布课件封面、占位图。公开接口只返回已签名或可公开访问的最终封面地址。

### 最近更新

新增公共 `recent` 聚合接口，将独立课件和系列转换为统一展示项后按 `latestPublishedAt` 倒序截取。系列更新时间综合系列自身发布时间与系列内已发布章节的最近发布时间。小程序按 `itemType` 跳转到课件详情或指定系列。

### 百炼 Qwen 音色

人声管理的新建入口只展示阿里百炼 Qwen 音色克隆。历史 MiniMax 档案继续可见，并提供迁移操作：使用原始样本创建 Qwen 音色，成功后将新档案设为 ready，再停用旧档案。芯之力配置保存最终可直接用于 TTS 的 voiceId 与 Qwen 模型，不保存 UI 选择器的复合 ID。运行时保留历史 MiniMax provider 分支，新增 Qwen 合成分支，避免破坏旧配置。

## 错误处理

- 所有写操作保留 `expectedUpdatedAt` 并发校验。
- 批量发布返回可定位的课件 ID 与失败原因，事务失败不产生部分发布。
- 上传对账将 `completing/completed/failed` 分别映射为继续等待、成功、展示失败；只有可中止状态才调用 abort。
- 系列未上传封面时不报错，自动使用回退封面。
- Qwen 上游错误保留供应商错误码和可读消息，密钥不写入日志或响应。

## 验收

- 连续新建两次生成两个 ID，第二次表单为空且不覆盖第一条。
- 下架课件可归档，公开端不可见，历史权益与学习记录保留。
- 多条 ready 课件可一次发布，任一不满足条件时全部不发布。
- 大文件 complete 超过 10 秒时前端不误报失败，后台最终状态可恢复。
- 上传任务轮询时表格不闪烁、不出现旧响应覆盖新状态。
- 系列可上传/替换/删除封面并选择比例；未上传时显示第一节封面。
- 最近更新可混排系列和独立课件，并正确跳转。
- 新建音色走百炼 Qwen；旧 MiniMax 可迁移且历史运行配置仍兼容。
