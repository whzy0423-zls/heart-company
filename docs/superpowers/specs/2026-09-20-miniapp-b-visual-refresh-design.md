# 小程序 B 方向视觉刷新设计

## 目标

将小程序视觉统一到“雾青 × 麦穗金”的轻盈成长风格，让用户第一眼建立对九型芯之力的记忆，并在首页快速理解测试、关系、课程和预约四类核心能力。

## 视觉方向

- 主色：雾青/深青，用于背景层、主要按钮和文字层级。
- 强调色：麦穗金，用于标签、图标标记和关键提示。
- 背景：低饱和青灰白，降低长时间浏览的视觉疲劳。
- 卡片：白色表面、细边框、适度圆角和轻阴影，保持微信小程序的清晰扫描感。
- 文字：中文优先，标题短而有记忆点，正文保持较高对比度。

## 首页结构

1. 品牌短句和“内在地图”定位。
2. 一个主视觉卡片，主 CTA 进入九型测试。
3. 四个核心工具入口：性格测试、关系合盘、成长课堂、预约咨询。
4. 主讲老师信任模块，沿用后台动态老师资料。
5. 今日成长引导模块，使用现有语录/内容数据，不新增接口。

## 约束

- 保持现有课程总开关行为：课程关闭时不展示课程入口。
- 保持现有 `goCourse`、`goMaterial`、`startTest`、`goRelation`、`goBooking` 导航函数。
- 不引入远程图片或新依赖；优先复用现有静态素材和动态接口内容。
- 微信构建要求所有 CSS 自定义属性只在全局 `:root` 中定义。

## 验收

- 首页首屏有唯一主行动入口，用户能快速找到测试。
- 四个工具入口在手机宽度下不横向溢出，点击区域稳定。
- 课程关闭后首页不出现课程入口。
- 既有配置、内容和构建测试通过。
