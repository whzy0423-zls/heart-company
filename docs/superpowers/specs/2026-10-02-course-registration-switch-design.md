# 课程报名总开关

后台「小程序管理 → 课程配置」增加「显示课程报名模块」。配置为 `home.miniappCourses.enabled`，缺省开启，明确关闭持久化到现有站点配置数据库，独立于视频课堂开关。

关闭后：首页隐藏报名课程推荐，快捷入口改为填写意向；报名页保留需求类型和真实提交表单，隐藏介绍、课程卡片、价格等展示区；公开课程详情旧链接转到报名表单，分享关闭。清除旧草稿/导航携带的课程绑定，保留用户填写内容。页面再次显示时刷新服务器配置。

后端拒绝新的指定课程报名与新支付请求，无课程绑定的表单继续入库并通知后台。订单、已购课程安排、支付状态同步和支付通知继续工作，关开关不删除数据。重新打开恢复已配置课程。

验证覆盖缺省/关闭/恢复、数据库存取、旧链接和草稿、真实表单提交、不重复支付及历史已购访问。生产发布沿用现有服务配置，不修改当前业务开关值。
