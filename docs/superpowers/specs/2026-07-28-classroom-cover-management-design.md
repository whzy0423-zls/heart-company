# 课堂课件封面管理设计

## 目标

为课堂课件补齐完整封面链路：管理员可上传自定义封面并选择 `16:9`、`9:16`、`1:1` 三种展示比例，默认 `16:9`；视频未上传自定义封面时使用第一可解码帧生成的云端封面，音频未上传时使用系统默认音频封面；后台和小程序始终通过统一的 `coverUrl` 读取当前有效封面。

## 当前问题

1. 视频上传完成后，`FFmpegCoverExtractor` 在第 1 秒截图，而不是首帧。
2. 自动封面对象保存在 `classroom_media_assets.cover_object_key`，公开接口和小程序却主要读取 `classroom_contents.cover_url`，导致对象已生成但页面仍可能没有封面。
3. 课件编辑器只有旧的 URL 字段，没有独立的封面上传、删除、比例选择和回退状态提示。
4. 音频课件没有统一的默认封面策略。
5. 对象存储中的封面需要通过后端生成可访问 URL，不能把内部对象路径直接暴露给客户端。

## 已确认交互

- 支持手动上传图片封面。
- 支持 `16:9`、`9:16`、`1:1`，默认 `16:9`。
- 手动封面优先于自动封面。
- 删除手动封面后立即回退到视频自动封面或音频默认封面。
- 视频自动封面取第一可解码帧，并按所选比例居中裁剪。
- 音频在没有手动封面时显示系统默认音频封面。
- 手动封面与视频自动封面均存储到现有课堂 OSS 文件桶。
- 不改变发布状态，不自动发布系列或课件。

## 数据模型

### `classroom_contents`

新增字段：

```sql
manual_cover_object_key TEXT NOT NULL DEFAULT ''
cover_aspect_ratio TEXT NOT NULL DEFAULT '16:9'
```

并为比例增加约束：

```sql
CHECK (cover_aspect_ratio IN ('16:9', '9:16', '1:1'))
```

保留现有 `cover_url` 作为历史数据兼容字段，不再作为新上传封面的存储位置。

### Go 模型

`classroom.Content` 增加：

- `ManualCoverObjectKey string`
- `CoverAspectRatio CoverAspectRatio`

`CoverAspectRatio` 为受限枚举，空值在输入归一化时按 `16:9` 处理；模型验证拒绝其他值。

## 有效封面解析

后台 DTO 和公开 DTO 都通过同一个解析器计算 `coverUrl`，避免两套规则漂移。优先级固定为：

1. `classroom_contents.manual_cover_object_key`
2. 视频媒体的 `classroom_media_assets.cover_object_key`
3. 历史 `classroom_contents.cover_url`
4. 音频系统默认封面
5. 空字符串

对象路径通过课堂 OSS signer 生成短期 GET URL。旧 `cover_url` 若是完整 URL 或现有站内资源路径则原样兼容。接口同时返回：

- `coverUrl`：已经解析的有效展示地址
- `manualCoverObjectKey`：仅后台管理接口返回，用于判断是否存在手动封面
- `coverAspectRatio`：后台和小程序均返回，供容器选择比例
- `coverSource`：后台返回 `manual | generated | legacy | audio-default | none`，用于展示“当前封面来源”

列表查询应一次性带出媒体封面字段，避免逐条查询；详情、学习进度等其他返回课件卡片的路径也复用同一解析规则。

## 手动封面上传与删除

新增管理接口：

```text
POST   /api/admin/classroom/contents/{id}/cover
DELETE /api/admin/classroom/contents/{id}/cover
```

### 上传

- 请求为 `multipart/form-data`，字段名 `file`。
- 接受 JPEG、PNG、WebP；通过内容嗅探校验实际图片类型，不只信任扩展名。
- 限制图片大小，沿用服务端上传配置中的合理图片上限。
- 上传到课堂桶路径：`classroom/covers/manual/{contentID}/{unique}.{ext}`。
- 新对象上传成功后，以事务/带并发条件的更新方式写入 `manual_cover_object_key`。
- 若替换旧手动封面，数据库更新成功后再删除旧对象；旧对象清理失败记录日志，但不回滚已经生效的新封面。
- 返回更新后的课件 DTO，其中 `coverUrl` 已指向新手动封面。

### 删除

- 清空 `manual_cover_object_key`，保留媒体自动封面。
- 数据库更新成功后清理原手动对象。
- 返回更新后的课件 DTO；`coverUrl` 自动变为生成封面、历史封面或音频默认封面。
- 重复删除按幂等成功处理。

### 权限和错误

- 复用 `Miniapp:Classroom:Write` 权限。
- 课件不存在返回 404，图片格式/大小错误返回 400，并发修改返回 409，存储服务异常返回 503。
- 删除接口永远不会删除 `classroom_media_assets.cover_object_key`。

## 视频自动封面

`FFmpegCoverExtractor` 接收课件比例并输出固定画布：

| 比例 | 输出尺寸 |
|---|---:|
| `16:9` | `1280x720` |
| `9:16` | `720x1280` |
| `1:1` | `1080x1080` |

截图规则：

- 去掉当前 `-ss 00:00:01`。
- 从视频开始位置读取第一张可解码视频帧。
- 使用等比放大后居中裁剪，确保输出无黑边且严格符合目标比例。
- 输出 JPEG，保持现有自动封面 OSS 生命周期和清理逻辑。
- 媒体上传完成时读取课件当前 `cover_aspect_ratio`，再生成自动封面。

比例在媒体已生成后发生变化时，需要重新生成自动封面：先生成并保存新对象，媒体记录切换成功后再清理旧对象。若课件有手动封面，仍允许更新比例，但页面继续显示手动封面；自动封面同步更新，以便以后删除手动封面时立即回退到正确比例。

## 音频默认封面

音频默认封面作为随应用发布的静态资源，不为每条音频重复上传对象。后端统一返回稳定的公开资源路径，后台和小程序使用相同图片。比例容器仍遵循课件的 `coverAspectRatio`，图片使用居中裁剪。

## 后台管理界面

在 `content-editor.vue` 的基本信息区域增加“课件封面”：

1. 比例分段选择器：`16:9`、`9:16`、`1:1`，初始值 `16:9`。
2. 按所选比例显示预览框，使用 `object-fit: cover`。
3. “上传封面”按钮选择图片并调用独立上传接口。
4. 存在手动封面时显示“删除手动封面”；删除后刷新为自动/默认封面。
5. 显示来源文案：手动上传、视频首帧、音频默认或历史封面。
6. 比例保存属于课件表单更新；若视频自动封面需要重新生成，后端负责完成并返回最新 DTO。
7. 上传中禁用重复操作，失败时保留当前预览并显示明确错误。

旧的自由填写 `coverUrl` 输入框从主交互中移除，但后端继续兼容历史值。

## 小程序展示

- 课堂列表和详情页继续使用 `coverUrl`，无需感知对象路径。
- 图片容器根据 `coverAspectRatio` 设置比例，统一 `mode="aspectFill"`。
- `coverUrl` 为空时保留页面级兜底样式，避免接口异常导致布局塌陷。
- 已发布内容只发生视觉字段变化，不改变访问权限、购买逻辑、播放逻辑和发布状态。

## 一致性与清理

- 手动封面对象只由课件记录拥有。
- 自动封面对象只由媒体记录拥有。
- 替换采用“先上传/生成新对象 → 更新数据库 → 删除旧对象”，避免数据库指向不存在的文件。
- 上传成功但数据库写入失败时立即清理新对象。
- 删除课件时清理手动封面；媒体现有删除流程继续清理自动封面。
- 所有对象删除都接受“对象已不存在”作为成功。

## 测试策略

### 数据库与模型

- schema 包含两个新字段、默认值和比例约束。
- 模型接受三个比例，空输入归一化为 `16:9`，拒绝非法比例。
- Store 创建、更新、查询完整读写新字段，且不破坏现有空标签修复。

### 封面解析

- 手动封面覆盖自动、历史和音频默认。
- 删除手动封面后视频回退自动封面。
- 没有对象路径时回退历史 URL。
- 音频无手动/历史封面时返回默认音频封面。
- OSS 签名失败返回可识别服务错误，不把对象路径暴露给客户端。

### 上传与删除 API

- 成功上传、替换旧封面、删除并回退、重复删除。
- 非图片、超限、课件不存在、权限不足、存储失败、数据库冲突与对象清理失败。
- 验证删除手动封面不会删除自动封面对象。

### FFmpeg

- 命令从首帧开始，不再包含第 1 秒 seek。
- 三种比例产生对应尺寸与居中裁剪 filter。
- 自动封面写入媒体记录，失败时执行对象清理。
- 修改比例时重新生成，数据库切换失败时清理新对象。

### 前端与小程序

- 新建课件默认 `16:9`。
- 三个比例均能保存并正确设置预览容器。
- 手动上传后显示手动来源；删除后显示自动/音频默认来源。
- 请求失败不会丢失当前表单和预览。
- 列表与详情使用后端返回的 `coverUrl` 和 `coverAspectRatio`。

## 非目标

- 不提供在线裁剪器、拖拽选区或图片滤镜。
- 不批量重做所有历史视频封面；历史内容在编辑比例或重新处理媒体时更新。
- 不改变系列封面。
- 不修改课程发布、权限、收费、播放和推送流程。
