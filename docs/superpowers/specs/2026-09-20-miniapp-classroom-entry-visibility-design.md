# 小程序视频课程总入口显隐设计

## 目标

后台提供一个明确的“显示视频课程入口”总开关。关闭后，小程序隐藏课程学习、课件资料、推荐课程等视频课程入口；老师资料和其他功能继续展示。已有课程、发布状态和用户数据不删除，重新打开后恢复。

## 配置与兼容

- 复用站点配置，字段为 `home.miniappLearn.classroom.enabled`。
- 旧配置未包含该字段时按 `true` 处理，避免升级后意外隐藏线上入口。
- 后台位置：`小程序管理 → 学习页管理 → 课堂精选`。

## 小程序行为

- 首页隐藏课程学习、课件资料、推荐课程和最新课件入口。
- 学习页隐藏课程、课件分类；若关闭时当前正处于这两个分类，自动切换至仍可用的语录分类。
- 测试结果页和预约完成页同步隐藏进入老师课堂的入口。
- 配置刷新后立即按最新值渲染；读取失败时保留上一次有效状态。

## 测试

- 后台测试覆盖默认开启、显式关闭、保存开关。
- 小程序配置规范化测试覆盖缺失默认开启与显式关闭。
- 页面契约测试覆盖首页和学习页均使用同一总开关。
