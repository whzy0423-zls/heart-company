# 芯之力动效新版官网设计

## 目标

在完全保留 `website-react` 的前提下，新建独立的 `website-react-motion`。新版继承旧官网全部业务、路由、公开 API、表单和内容，只重构视觉表达、内容编排和交互动效。

## 隔离边界

- `website-react` 是旧版稳定官网，文件内容和部署配置保持不变。
- `website-react-motion` 是可独立安装、开发、测试和构建的新版官网。
- 新版继续读取相同的公开站点配置和业务 API，但不从旧版源码目录运行时导入组件。
- 新版使用独立的包名、开发端口和构建目录，可单独预览和删除。

## 视觉方向

视觉语言采用“高端编辑感 + 克制科技动效”，而不是通用科技模板。整体以柔和白、石墨黑、深森林绿为主，珊瑚红和冷蓝只用于少量视觉焦点。中文标题使用有编辑感的宋体系统，正文使用现代无衬线系统。

首屏直接表达“芯之力 / 九型人格 / 自我探索”，让品牌和业务在第一视口内成为主要信号。核心视觉是动态九型轨道：九个节点围绕中心缓慢呼吸，并根据滚动与指针产生轻微空间响应。

## 动效基准

参考视频中的五类工具被转译为一套统一动效系统：

- Godly：非模板化排版、强标题层级、章节式明暗节奏。
- Aceternity：局部聚光、边框高光、文字与卡片微交互。
- GSAP 风格：滚动文字揭示、图片视差、粘性章节和空间连续性。
- Lenis 风格：桌面端平滑滚动；键盘、锚点和原生可访问行为保持可用。
- MotionSites：每个章节只保留一个明确的视觉动作，形成叙事节奏。

实现优先使用浏览器原生能力和轻量 React 逻辑，只有滚动编排需要时才引入成熟库。所有动画遵循统一时长、缓动和位移范围，并响应 `prefers-reduced-motion`。

## 页面结构

首页保留旧版业务顺序，但重新组织视觉层级：

1. 品牌首屏：品牌名、业务价值、主行动和动态九型轨道。
2. 九型探索：九种类型以可交互轨道与编辑式列表呈现。
3. 课程体系：三阶段课程采用滚动叙事，业务文案和跳转不变。
4. 导师与内容：导师、精选视频和金句使用真实媒体资源。
5. App 与企业服务：保留下载、状态、咨询和企业培训入口。
6. 报名转化：保留现有字段、校验、提交 API 和结果反馈。

旧版所有独立路由继续存在。内页继承新版全局导航、排版、色彩、按钮、表单和基础进入动效，具体业务结构不做删减。

业务完整性按路由和能力矩阵验收。路由至少覆盖首页、导师、三阶段总览与三个阶段详情、观看、课件、课程、游戏、九型总览与九型详情、金句、心语列表与详情、报名。能力至少覆盖运行时站点配置、访问统计、报名提交、游戏结果、视频播放与音乐互斥、App 发布信息与下载，以及全部本地内容和媒体资源引用。

## 响应式与可访问性

- 375、768、1024、1440 像素视口均无横向溢出或文字遮挡。
- 手机端取消指针跟随、重视差和粘性长动画，保留轻量揭示和明确反馈。
- 键盘焦点始终可见，按钮和链接最小触控高度为 44 像素。
- 语义标题顺序、图片替代文本、表单标签和状态播报保持完整。
- 降低动态偏好下关闭平滑滚动、持续旋转、视差和大位移动画。

## 验收

- 旧官网基线哈希在工作结束时完全一致。
- 旧官网基线存放在旧站目录之外，对排除既有 `node_modules`、`dist` 和上传缓存后的全部文件执行双向路径集合与 SHA-256 比较，新增、删除和内容变化都会失败。
- 新版包含旧版全部路由、API 调用、交互行为、数据入口与内容资源引用，并通过逐路由 smoke test。
- 新版测试与生产构建通过。
- 桌面和移动端对每类页面截图，证明品牌突出、没有遮挡和横向滚动。
- 浏览器自动检查首页全部动效章节，记录滚动前后状态和截图，验证指针响应、章节转换与降低动态降级，同时确认控制台无错误。
