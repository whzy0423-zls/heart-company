# 小程序首页模块配置设计

## 目标

在现有“小程序管理 → 首页管理”中管理紫色新版首页的全部内容模块。后台可以修改文案、显隐和功能入口内部顺序，但不能修改页面跳转目标，也不能自由输入图标或颜色，从而保证首页结构和视觉质量稳定。

## 范围

首页大模块按现有顺序固定：

1. 顶部轮播图
2. 顶部品牌区
3. 主视觉区
4. 功能入口区
5. 成长内容区

轮播图继续使用现有 `home.miniappCarousel`。其他首页模块新增在 `home.miniappHome` 下。

不包含：自由页面路径、外部链接、自定义 CSS、自定义颜色值、自定义图片图标和首页大模块拖动排序。

```json
          }

```

功能入口的 `key` 固定为 `test`、`relation`、`learn`、`profile`，每个键最多出现一次。后台可以调整这四项在数组中的顺序和显隐。

## 固定行为映射

小程序根据入口 `key` 决定跳转，后台不保存页面路径：

| key | 固定目标 | 跳转方式 |
| --- | --- | --- |
| `test` | `/pages/test/test` | `navigateTo` |
| `relation` | `/pages/relation/relation` | `navigateTo` |
| `learn` | `/pages/learn/learn` | `switchTab` |
| `profile` | `/pages/profile/profile` | `switchTab` |

主视觉按钮固定进入人格测试，顶部头像固定进入成长档案，成长内容固定进入老师课程。

## 预设图标与配色

图标只允许内置枚举：`compass`、`relation`、`book`、`growth`、`spark`、`heart`。主题色只允许：`blue`、`purple`、`orange`、`pink`、`cyan`。

小程序使用 CSS 修饰类渲染预设图标和主题。未知枚举回退到入口键对应的默认图标和颜色，不渲染任意后台样式。

## 后台交互

“首页管理”使用单页折叠分区，顺序与小程序一致。轮播图沿用现有编辑器；品牌、主视觉、功能入口和成长内容分别使用折叠面板。

每个模块提供启用开关和文案字段。功能入口卡片提供标题、说明、图标下拉、主题色下拉、启用开关、上移和下移。入口键和固定跳转目标只读展示。

保存时复用现有站点配置接口，必须保留 `home` 中未知字段、官网内容和轮播配置。

## 小程序数据流

首页挂载时继续先读取站点配置缓存，再请求公开配置。新增规范化工具将缺失或异常的 `miniappHome` 合并到当前紫色首页默认值，因此尚未配置后台时页面完全保持当前外观。

规范化规则：

- 非字符串或空字符串文案回退默认值。
- 非布尔 `enabled` 回退 `true`。
- 丢失的固定入口自动补齐到数组末尾。
- 重复或未知入口键被忽略。
- 未知图标和主题回退默认枚举。
- 所有入口关闭时隐藏功能入口区，不留下空白。

## 错误处理

网络刷新失败时保留缓存或默认首页。单张轮播图片失败继续沿用现有剔除机制。配置内容异常不影响首页其他模块，规范化过程不抛出到页面层。

## 测试

- 后台：缺失配置初始化、字段保留、固定入口补齐、排序显隐、图标与主题选项、保存不破坏轮播和其他首页字段。
- 小程序：默认兼容、异常配置回退、重复与未知入口过滤、入口顺序、全部隐藏、固定跳转映射和预设样式契约。
- 回归：现有轮播测试、小程序完整 `test:config`、Go 站点配置接口测试和后台页面测试。
