# 无限画布后台主题同步设计

## 目标

让嵌入后台的无限画布继承后台当前主色、背景、卡片、文字、边框、圆角与深浅模式，去掉原有米色/石色视觉，同时保留独立打开时的可用默认主题。

## 方案

- 后台 Vue 容器读取根节点计算后的语义 CSS 变量，并通过 `postMessage` 发送给 iframe。
- Vue 容器监听后台根节点主题属性变化，在主题切换时重新发送。
- React 画布验证消息来源和数据结构，将颜色规范化后写入自身 CSS 变量，并同步 `light/dark` 状态。
- Canvas 绘制主题改用 CSS 语义变量，节点激活、选区和交互态统一使用后台 `primary`。
- Ant Design Provider 接收同步后的主色和圆角，避免弹窗、按钮仍保留原黑白主题。

## 兼容与回退

- 独立打开画布时使用与后台一致的蓝白默认 Token。
- 无效消息、未知字段或空值不会覆盖默认值。
- iframe 仅接受来自父窗口且同源的主题消息。

## 验证

- 单元测试覆盖主题快照提取、消息校验、HSL 颜色规范化和 DOM Token 应用。
- 运行 React/Vue 类型检查和无限画布构建。
- 浏览器验证浅色主题、深色主题、节点选中态及后台主题切换。
