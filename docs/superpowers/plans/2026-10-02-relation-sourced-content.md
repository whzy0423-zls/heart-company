# 有来源的关系合盘内容

**Goal:** 用真实可核对的原始资料，丰富45种独立配对的关系解读与81组有序选择，同时保持好友与朋友圈分享。

**Architecture:** 逐页阅读 Enneagram Institute 配对原文，撰写简短中文转述；把理论描述、原创情境练习与 Gottman 沟通方法区分呈现。资料与页面分析迁入普通分包，原页面 URL 不变。来源列表提供标题、机构、用途及原文地址，微信端复制原文链接，H5 可直接阅读。

**Tech Stack:** uni-app / Vue 3 / 微信普通分包 / Node行为测试。

## 内容与证据

- 45篇官方配对页面：每组独立主题、可能互补之处、摩擦循环、原创情境与练习问题。
- Gottman Institute 的冲突应对和温和开场文章：整理可操作的沟通工具，明确这些方法原本来自伴侣沟通语境。
- Hook等人的系统综述：只按已获得的摘要与书目信息介绍证据边界，不把类型理论写成配对预测。
- 原网页全文仅暂存本地临时目录用于阅读；仓库保存简短原创摘要、出处和核对记录。
