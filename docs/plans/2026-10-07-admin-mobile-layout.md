# 后台管理手机适配

## 范围与验收

同一后台账号、菜单权限、接口和数据在电脑与手机浏览器共用。本次只修改 `nx-backend/apps/web-antd` 的展示层；Flutter App、用户 H5、原生工程及后端业务不在修改范围。

| 验收项 | 手机浏览器 | 电脑浏览器 |
| --- | --- | --- |
| 入口 | 原后台地址登录；侧栏按钮打开完整授权菜单 | 原地址、菜单与工作区保持可用 |
| 权限 | 新增/编辑/查看仍取决于原权限码 | 相同权限码及行为 |
| 列表 | 筛选/操作换行；宽表局部横向滚动，保留所有列 | 保留原表格和固定列；过宽表可滚动 |
| 详情与表单 | 抽屉不超出屏幕；正文可纵向滚动；关闭、保存、取消可达 | 保留原尺寸与布局 |
| 主要状态 | 加载、空数据、列表、详情、编辑、校验失败仍可操作 | 保持现有状态 |
| 成功和失败 | 保持原成功/错误提示及提交逻辑 | 不变 |
| 持久化 | 使用相同后台 API，不新增存储或同步逻辑 | 不变 |

## 已发现根因

- 4 个侧边抽屉使用 560–720px 固定宽度，组件默认未限制最大宽度。
- 手机表格左右固定列（例如订单 230px + 156px）占满内容区，遮挡中间字段。
- 部分多列表格没有设置横向滚动，压缩内容或撑开页面。
- 过滤工具栏、卡片标题、少量多列表单未覆盖窄屏或横屏宽度。
- 日期范围弹层默认双月份横排宽 560px；手机侧栏仅依靠 mouseleave 收起，触摸选中菜单后仍遮挡新页面。

## 实现

后台专用 body 标记与响应式样式覆盖（包括 teleport 到 body 的抽屉/弹窗），仅手机断点生效。内容容器允许收缩，工具栏自然换行，表格保留自身滚动，手机取消固定列粘连。对审计确认的表格、筛选网格与模型表单补页面级响应式设置。保留既有卡片模式与画布交互，不全局把所有网格/Space 强制单列。

手机日期双月面板改为纵排并限高滚动；后台布局在手机成功导航或重复点击当前菜单时主动收起侧栏，退出布局时清理钩子。客户三页筛选栏按内容宽度 flex-wrap，保留桌面控件原基础宽度，避免 844px 横屏和 1024px 小窗口仍然溢出。

## 验证与发布

- 真实 Vue 应用、路由、认证状态及 Ant Design 组件，接口使用本地固定样本；不写线上业务数据。
- 320/360/390/430px 手机、横屏/平板、1024/1440px 电脑；检查登录、菜单、筛选、新增、详情、关闭、表格横向滚动以及大字号。
- TypeScript 检查、相关单测、生产构建、代理权限回归。
- 合并后只发布后台静态资源/后台容器；保留旧镜像用于回滚；复核线上资源及其他服务未变化。
- 模拟视口测试与实机兼容性分开记录，不宣称覆盖所有品牌实机。
