# 合盘详情与分享

## 本次变更

- 保留九型人物选型与点击原图预览，扩展结果为相处底色、双方需求及支持方式、优势、压力提醒、沟通示例、核心驱动和三个行动练习。
- 根据 9 种型号与三中心组合生成内容，支持 81 组有序组合。移除原来固定的契合分数，改为同型照见、同频共鸣、互补同行等关系特点。
- 新增 45 组无序配对的逐组资料转述（每组独立主题、优势、摩擦方向），并为每组提供一条明确标注为原创的生活情境练习。顺序交换只改变“我 / TA”的需求与对话方向，不改变该组理论材料。
- 详情新增“有分歧时，也能好好说话”折叠区，包含温和开场、欣赏、承担自己的部分、暂停并约好回来四个沟通工具；新增“这份解读，参考了什么”折叠区，可查看 Enneagram Institute、Gottman Institute 和九型研究综述的出处。
- 新增好友及朋友圈分享钩子、页面分享入口。分享链接只携带 `myType`、`taType` 两个 1–9 型号；首次打开直接生成同一组解读，无登录或本地缓存依赖。
- 分享收件人页面使用一方、另一方与明确型号表述；示例对话保留第一人称。非法参数回到选择页并提示，重置后不再分享旧组合。
- 朋友圈通过微信右上角菜单实际分享，页面按钮提供原生操作指引；朋友圈单页可以直接读结果，换组选型提示进入完整小程序。
- 复用已发布的 HTTPS JPEG 封面，实测 HTTP 200，未增加打包图片。
- 关系页及其 45 组资料迁入 `pages/relation` 普通分包，URL、主包依赖和朋友圈 scene 1154 行为保持不变。
