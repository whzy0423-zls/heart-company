# 微信开发者工具上传连接重置排查

## 现象

2026-10-02，微信开发者工具 Nightly 2.02.2606032（macOS arm64）在打包完成后的上传阶段报错：`read ECONNRESET`。

## 已验证

- 当前生产包 `miniapp/dist/build/mp-weixin` 为 2,072,879 字节，低于 2,097,152 字节限制，剩余 24,273 字节。
- 19 个页面编译文件完整，9 张合盘人物抠图已包含；23 张保留图片与源文件逐字节一致。
- 包资源校验、生产 API 配置校验及项目配置测试通过。
- 开发者工具使用系统代理；系统 HTTP、HTTPS、SOCKS、自动代理均未开启，终端代理环境变量未设置。
- 安装资源中的预览接口为 `servicewechat.com/wxa-dev[-new]/testsource`，上传接口为 `servicewechat.com/wxa-dev[-new]/commitsource`。
- 对上述接口发送不含登录信息和查询参数的 HTTPS 请求，curl 均在 TLS 阶段发生连接重置，未收到 HTTP 响应。
- Python 独立测试同样在 TLS 阶段收到 `ConnectionResetError`（errno 54）。DNS 返回的两个地址分别以正确 SNI 测试，均出现相同错误。
- 对照 `mp.weixin.qq.com` 返回 HTTP 200，`developers.weixin.qq.com` 返回 HTTP 302，均成功建立 TLS 1.3 连接。
- `/etc/hosts` 未覆盖上述域名。

## 结论与下一步

现有证据将故障定位到当前电脑至微信代码上传服务的 TLS 连接。尚不能仅凭连接重置确定是本地网络链路、中间网络设备还是服务端造成；没有证据表明由本次图片改动、包体大小或业务服务器引起。

换用手机热点或另一条网络后，先验证预览，再重新上传现有生产包。以开发者工具明确显示上传成功为准；本次排查期间没有成功更新体验版。

未修改代码、系统网络、代理、证书检查或开发者工具服务端口。CLI 检查提示服务端口未开启，因此未通过 CLI 发起上传。

## 同日再次上传

19:53:09 的开发者工具日志再次记录相同的上传错误。用户确认该次上传仍使用原来的 Wi-Fi，尚未切换手机热点或其他网络，因此暂时没有不同网络的对照结果。系统当前默认路由走 Wi-Fi 接口 `en0`，没有活动的系统 VPN 连接；这仍不能排除网络中间设备导致重置。
