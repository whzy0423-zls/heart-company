# 已报名课程详情跳转修复 — 2026-10-02

## 问题与修复

课程报名详情已收到已购结果时，底部可以显示“查看我的课程”，但此前按钮仍受公共课程配置的加载状态限制。慢网下点击没有响应。原入口直接调用 `uni.navigateTo`，页面层级达到微信上限或跳转失败时，也没有失败提示。

- 已确认购买的课程入口不再等待公共课程配置；未购买用户继续等待最新配置和报名状态，避免误进入支付。
- 点击后显示“正在打开课程”并阻止重复点击，导航结束后解除锁定。
- 统一使用 `courseNavigation`，按报名 ID 复用已有页面；达到十层页面栈时使用 `redirectTo`，普通跳转失败时只重试一次替换跳转。
- 最终失败显示“课程页面暂未打开，请重试”。离开页面、卸载页面或切换账号后的延迟失败回调不会触发恢复跳转。
- 不修改支付金额、现有订单和后端购买权限校验。
