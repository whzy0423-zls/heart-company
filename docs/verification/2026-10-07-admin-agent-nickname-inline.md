# 后台代理号与昵称同格显示

## 验收与实现

手机无需横滑到单独昵称列即可识别代理：代理排行、代理列表、下级明细的第一列统一为“代理号 / 用户昵称”，同一单元格先代理号标签、紧接昵称，长昵称允许换行。保留后台ID/账号后续列，删除重复独立昵称列和原代理号旁“后台自动生成”说明。

顶部“我的代理号”、下级明细说明和编辑弹窗同样补齐昵称。复用现有appUserNickname及排行列表外用户查询与回退，不改接口或数据。复制代理号、海报、编辑提交、权限、订单分成仍使用原ID/代理号。

仅后台Vue展示；用户H5、Flutter App、原生工程及后端无改动。上一轮手机表头/数据区触摸与横屏规则完整保留。
