This copy is adapted for the Nine Xing admin application. It retains the canvas
library and canvas editor while removing standalone home, image generation,
video generation, assets, configuration, prompt-library navigation, analytics,
account, update, advertising, sponsor and WebDAV pages. The application is built
as an isolated React/Vite bundle and embedded by the Vue admin.
