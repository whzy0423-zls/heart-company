# 九型芯之力分销与代理系统设计

## 目标
支持管理员授予代理权限，形成最多三级的稳定邀请关系，并对已支付订单进行可审计、可幂等的佣金计算与结算。

## 核心模型
- `代理人`: 绑定用户、唯一代理号、层级、上级代理、状态。
- `邀请关系`: 用户首次绑定代理后不可随意迁移；禁止自邀、重复绑定和闭环。
- `佣金规则`: 按版本生效，记录每级比例及适用商品/订单范围。
- `佣金账本`: 订单、规则版本、代理链路和金额快照；正向入账与退款冲正均幂等。
- `结算单`: 按代理和时间范围锁定可结算账本，支持预览、创建、审核、驳回、取消、登记打款。

## 关键流程
1. 管理员为用户授予代理权限并生成代理号。
2. 代理分享邀请链接；注册/登录时承接代理号。
3. 首次绑定时校验层级、状态、自邀和闭环。
4. 支付成功事件以订单号幂等生成佣金及链路快照。
5. 退款事件生成冲正账本，不修改历史正向账本。
6. 结算预览锁定账本，审核后登记实际打款；重复请求不重复占用或支付。

## 权限与审计
后台按管理员权限、代理本人范围隔离数据；所有授予、停用、规则变更、结算状态变化和打款登记写入审计日志。代理只能查看其下属树及聚合数据，不暴露无关用户隐私。

## 商用约束
金额使用最小货币单位整数；时间统一 UTC 存储；接口使用幂等键；规则和佣金采用不可变快照；退款、撤销、重复回调和并发结算必须可重放且结果一致。上线前需配置真实支付回调、提现/财务对账、风控阈值、隐私政策和数据保留策略。

## 已实现入口
后端实现位于 `apps/server/internal/server/distribution*.go`、`app_payment_settlement.go` 和 `internal/db/schema.sql`；管理端与 App 分别提供代理管理、佣金/结算管理和推广中心页面。
