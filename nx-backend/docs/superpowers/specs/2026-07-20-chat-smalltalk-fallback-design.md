# 寒暄问答与模型失败兜底设计

## 问题

“你在干嘛”被知识库中的“你在自己的方向”和“你早干嘛去了”两个短语误命中；同时 MiniMax 当前模型不可用，生成失败后 RAG 返回了资料拼接兜底，最终形成答非所问的长回答。

## 设计

- 识别“你好、在吗、你在干嘛、你是谁”等短寒暄，跳过知识库检索。
- 寒暄优先调用模型；模型不可用时返回自然的本地寒暄，不展示错误或九型资料。
- 普通问题模型失败时，不再返回资料拼接长文；返回简短可重试提示，并保留已发送消息。
- RAG 停止把“你在、干嘛、怎么、什么”等泛化短词作为相关性证据，避免短句误命中。
- 模型连通性仍由后台配置页选择账号实际支持的模型；程序不能假定某个模型名称。

## 验证

- “你在干嘛”不携带知识库来源，模型失败时仍回答自然。
- “在吗”“你好”“你是谁”同样不检索资料。
- 明确的九型问题仍能检索高相关资料。
- 普通问题模型失败时不再出现“我先按你问到的重点检索了九型资料”。
