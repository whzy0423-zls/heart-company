# 我的故事 Story Skills

这是按现有 App 故事类型 key 生成的 Skill 发布包，共 40 个 Skill：

- `realistic` 真实叙事：8
- `novel` 小说叙事：8
- `fairy_tale` 童话寓言：8
- `myth` 神话传说：8
- `folk` 民间故事：8

原始资料扫描记录：920 个文件；已读取正文 126 个；文本层为空 500 个；文本不足 50 个；非文字资源 244 个。

## 发布边界

`SKILL.md` 是写作行为规则，不是原始书籍复制品。原始 PDF、PPT、音频和压缩包不上传到故事 Skill。OCR 后只更新 `references/source-map.json` 或知识包，不改变 App 的五个类型 key。

## 接入方式

后台“我的故事管理”按目录逐个上传 `SKILL.md`，类型字段必须使用目录名对应的 key。保存草稿后，用真实材料分别测试事实保持、风格命中和类型隔离，再发布。

后端运行时会把已发布规则与用户补充要求合并，并把规则限制在约 6000 个中文字符以内，因此每个 `SKILL.md` 应保持短、可执行、可验证。
