# 老师个人品牌小程序 · UI 交付记录

2026-09-30，在现有 main 分支实现，修改范围为 miniapp。

## 页面与视觉

米白背景、暖棕强调、中文衬线标题和轻边框，以老师本人和真实内容作为主视觉。

- 首页：真实老师肖像、老师详情入口、公开视频、课程与咨询入口。
- 老师详情：简介、擅长方向、学习经历与师承照片。
- 日常：19 段真实短讲，支持关键词搜索、主题筛选、学习资料与札记。
- 视频详情：媒体优先，保留权限、微信支付、播放恢复与进度逻辑。
- 课程详情：课程介绍、学习内容、注意事项及带入报名意向。
- 报名：课程、咨询、企业共学，表单校验、信息使用说明、草稿和提交反馈。
- 我的：用户资料、报名状态、探索记录与已有服务入口。

## 数据说明

韩常青老师资料来自现有 Teacher 页面和站点配置；照片来自项目已有素材。公开视频内容来自公开接口快照，标题与本地视频封面逐一核对，来源见 `miniapp/preview-data/`。课程排期、价格及林小满学员档案为演示资料，页面已标注。

预览通过 `DEV && VITE_UI_PREVIEW === 'true'` 开关启用。演示登录、站点缓存、报名草稿与意向使用独立存储键；所有 API 请求均由本地适配结束。正式构建不包含预览会话与报名适配。未设置该开关时保留实际 API 行为。
