# 九型芯之力小程序首页现代能量面板设计

## 1. 目标与范围

本阶段只重做 `src/pages/index/index.vue` 首页，在现有蓝色渐变与玻璃质感基础上提升视觉丰富度、现代感和内容层次。

不修改九型测试算法、登录、支付、预约、后端接口及其他页面业务。首页所有入口继续调用现有路由和 tabBar 页面。

## 2. 设计方向

采用用户确认的“多彩能量面板”方向：

- 以蓝紫渐变作为品牌主色和首屏视觉中心。
- 使用蓝青、紫粉、青绿、橙红四组受控渐变区分核心入口。
- 保留当前版本的轻透、圆角和柔和阴影，但避免所有区域都使用相同白色玻璃卡片。
- 通过大主视觉、四宫格入口和横向成长内容形成三种不同内容节奏。
- 页面可以丰富、年轻和有能量感，但主操作仍只有“开始测试”一个。

## 3. 首页结构

### 3.1 顶部品牌区

- 左侧显示“九型芯之力”品牌文字。
- 右侧提供简洁的个人入口，点击切换到 `pages/profile/profile`。
- 顶部元素保持轻量，不与主视觉争夺注意力。

### 3.2 沉浸式主视觉

- 使用深蓝到紫色的渐变容器，叠加低透明度光斑和几何装饰。
- 主标题强调“发现/解锁人格能量”的价值，不堆叠过长说明。
- 复用 `/static/wheel.png`，为图片声明固定尺寸，并用 CSS 光环、半透明底层和阴影增强立体感。
- 唯一主按钮为“开始测试”，点击进入 `/pages/test/test`。
- 主视觉的装饰不承载交互，不能遮挡标题和按钮。

### 3.3 四宫格能量入口

四个入口使用统一组件结构和不同渐变：

| 入口 | 色彩 | 行为 |
|---|---|---|
| 人格测试 | 蓝青 | `navigateTo('/pages/test/test')` |
| 关系合盘 | 紫粉 | `navigateTo('/pages/relation/relation')` |
| 老师课程 | 青绿 | `switchTab('/pages/learn/learn')` |
| 成长档案 | 橙红 | `switchTab('/pages/profile/profile')` |

每张入口卡包含标题、短说明和统一风格的 CSS 几何图标，不新增 SVG 资产。正式入口不使用 emoji。卡片整体可点击，触控区域不小于 44px，并提供按压反馈。

### 3.4 今日成长内容

- 首页底部增加一张横向内容卡，展示一条成长洞察和学习引导。
- 文案来自现有本地内容或稳定静态文案，不新增后端接口。
- 点击整张卡切换到 `pages/learn/learn`。
- 使用与四宫格不同的浅色媒体布局，避免页面从上到下只有渐变色块。

## 4. 视觉系统

### 4.1 色彩

- 页面背景：浅蓝灰 `#F3F6FC`，允许叠加低透明度蓝紫径向光晕。
- 主视觉：`#1D4ED8` 到 `#7C3AED`，辅助亮蓝 `#38BDF8`。
- 人格测试：`#2563EB` 到 `#38BDF8`。
- 关系合盘：`#7C3AED` 到 `#EC4899`。
- 老师课程：`#0F766E` 到 `#34D399`。
- 成长档案：`#EA580C` 到 `#FB7185`。
- 主文字：`#0F172A`；次级文字不浅于 `#64748B`。

渐变仅用于主视觉和四个功能入口。普通信息区域使用浅色表面与边框，防止颜色过载。

### 4.2 排版和间距

- 页面内容最大宽度沿用 `900rpx`。手机与平板都保持四张入口卡为两列网格；平板只增加卡片内部留白，不扩展成四列，避免信息过度横向分散。
- 主标题：52–60rpx，800–900 字重，紧凑行高。
- 区块标题：30–34rpx，800–900 字重。
- 卡片标题：27–30rpx，700–800 字重。
- 正文：24–28rpx，行高 1.5–1.7。
- 使用 8rpx 基础间距系统；页面横向留白 28rpx。
- 卡片圆角控制在 24–36rpx，不使用每个区域都相同的超大圆角。

### 4.3 图形和层次

- 装饰图形使用伪元素和普通 CSS 几何形状，兼容微信小程序与 H5。
- 不依赖复杂滤镜；必要的 `filter` 效果必须有无滤镜兜底。
- 普通内容使用边框、留白和浅阴影分层；深阴影只用于主视觉和少量重点媒介。

## 5. 交互和动效

- 按钮和入口卡按下时使用轻微缩放与透明度反馈。
- 过渡时长控制在 150–260ms，只动画 `transform` 和 `opacity`。
- 九型圆盘允许低幅度、慢速漂浮，但必须在 `prefers-reduced-motion` 下关闭。
- 所有可点击卡都提供明确的可访问名称和 `role="button"`。
- 不依赖 hover 才能发现操作。

## 6. 数据与异常边界

- 题目总数继续读取 `QUESTIONS.length`。
- 首页不发起新的网络请求，因此无需新增加载、失败或空状态。
- 跳转沿用 uni-app 的 `navigateTo` 和 `switchTab`，不改变现有页面栈语义。
- 图片加载失败时通过图片 `error` 事件关闭九型圆盘图片，并显示 CSS 绘制的圆环与数字 9 兜底；主视觉仍保留渐变、光环、标题和主要操作。

## 7. 文件边界

- 主要修改：`src/pages/index/index.vue`，负责首页结构、跳转和页面特有样式。
- 可选小幅修改：`src/styles/apple-mobile.css`，仅在确有复用价值时补充语义 token；不为单页样式扩大全局改动。
- 测试修改：`scripts/ui-compat.test.mjs`，增加首页入口、触控尺寸、图片尺寸、可访问标签和减少动效的静态断言。

现有首页测试中绑定旧 `.grid__item`、`aria-pressed`、老师和课程文案的断言需要按新结构有意识地更新；必须继续保留入口数量、可访问名称、按压反馈、老师/课程内容和无 AI 入口等行为约束。

不新增 UI 框架、外部字体或后端接口。

## 8. 验收标准

- 首页主视觉、四宫格和今日成长区在 375px、390px 及平板宽度下无横向滚动。
- 页面保留底部 tabBar 安全区，内容不被遮挡。
- 所有核心入口跳转到现有正确页面。
- “唯一主操作”指首页只有一个视觉上占主导地位的 CTA；四张功能卡仍然是可交互的次级入口。
- 主要触控区域不小于 44px，按压反馈清晰。
- 文字与背景具备足够对比度，功能含义不只依赖颜色表达。
- 九型圆盘声明固定尺寸，加载时不引发布局跳动。
- H5 与微信小程序均构建成功。
- `npm run test:config` 通过。
- 对首页进行实际截图或渲染验收，检查首屏层次、颜色控制和小屏适配。
