# 老师卡片紧凑布局设计

## 问题

老师卡片当前使用头像与全部文字并列的双栏结构。老师简介较长时，简介始终被限制在右栏，头像下方会留下贯穿整张卡片的大块空白。

## 已确认方案

卡片改为两层信息结构：

1. 顶部 `teacher-card__header` 横排展示头像与老师姓名、头衔。
2. 下方 `teacher-card__details` 通栏展示老师简介与标签。

图片继续使用现有后台头像、`aspectFill`、加载失败占位和黑金暖白设计变量，不改变数据结构、图片资源或课堂入口。

## 视觉规则

- 头像固定为紧凑方形缩略图，避免拉伸。
- 姓名和头衔只占顶部信息区，允许自然换行。
- 简介从卡片左边缘开始通栏排版，消除头像下方空列。
- 卡片继续使用当前圆角、边框和暖白底色，不引入绿色、蓝色或额外装饰。
- 小屏微信设备上保持文字可读，不使用定位或浮动布局。

## 验证

- 源码契约测试确认顶部信息区与通栏详情区存在。
- 契约测试确认简介和标签位于详情区，而不是头像右侧的正文列。
- 运行 `npm run test:config`。
- 检查 `dist/dev/mp-weixin/pages/learn/learn.wxml` 和 WXSS 中的新结构。
