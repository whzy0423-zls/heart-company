# 老师课堂布局精修设计

## 目标

保留当前深石墨蓝、香槟金、暖米白的视觉体系，只调整页面信息层级和空间比例，让用户进入课堂后更快看到可学习内容，并消除课程卡重复操作。

## 当前问题

- 顶部介绍区标题、说明、三个标签连续堆叠，占用首屏过多。
- “继续学习”卡片高度偏大，与下方课程分类割裂。
- 分类切换视觉重量较高，进一步推迟课程内容出现。
- 课程封面同时出现“立即学习”浮层和底部“立即学习”按钮，操作重复。
- 课程标题、简介、权限、老师、时长分散，阅读顺序不清晰。

## 采用布局

### 1. 紧凑课堂头部

- 保留深蓝渐变和金色眉题。
- 标题精简为“视频与音频课件”。
- 说明压缩为两行以内：“按自己的节奏学习，也可以跟随系列课程持续进阶。”
- 标签由三个缩减为“独立课件”“系列课程”两个轻量标签。
- 通过更小的内边距和字号，把首屏空间让给课程内容。

### 2. 紧凑继续学习

- 保留完整按钮语义和学习进度。
- 顶部一行展示“继续学习”、课程标题和“继续”动作。
- 进度条和已学习时间紧密放在同一信息组内。
- 减少垂直空白，但触达区域仍不小于 88rpx。

### 3. 清晰分类切换

- 分类条保持双列，不做悬浮或复杂动效。
- 激活项使用深蓝文字、白色表面和香槟金细线/光晕；未激活项弱化。
- 总高度收紧，但两个 tab 仍各自满足 88rpx 触达。

### 4. 单一操作课程卡

- 封面保留权限和内容类型标签。
- 封面中央只显示简洁播放图形，不再显示第二个“立即学习/查看课件”文字按钮。
- 正文顺序：内容分类 → 标题 → 简介 → 老师/时长 → 唯一主操作。
- 独立课件只有一个“立即学习”；系列课程只有一个“查看课件/购买”操作。
- 16:9、9:16、1:1 封面继续使用后台比例，但统一收紧最大视觉高度。

## 交互与兼容

- 不改变 API、购买流程、继续播放位置、系列展开和路由。
- 所有点击仍使用原生 `button`，不产生嵌套交互。
- 图片保持懒加载与错误兜底。
- 保留加载、错误、空状态与支付反馈。

## 验证

- 页面契约测试验证紧凑头部、两个标签、紧凑继续学习、单一课程 CTA、封面无重复文字 CTA。
- 运行课堂 focused test、UI/WXSS 兼容测试、全量测试和微信构建。
- 保持现有 `npm run dev:mp-weixin` watcher，检查最新开发产物。
