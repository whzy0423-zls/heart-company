# 老师课堂入口与内容平台感 UI 设计

**日期:** 2026-07-28
**范围:** 小程序首页、学一学页老师课堂精选区、老师课堂列表页、课件详情页。
**已确认选择:** 首页入口采用「方案 3」；课堂列表采用 A「内容平台感」。

## 背景

用户喜欢当前首页整体风格，但觉得“老师课堂”的入口位置不够明确，进入课堂后查看课程的视觉不够理想。后台已具备视频/音频课件发布能力，小程序侧需要让已发布课件更像可浏览、可播放的内容平台。

## 目标

1. 首页不大改整体视觉，只新增一个更明显的“老师课堂”强入口。
2. “学一学”页面保留老师课堂精选区，并强化视频/音频课件的入口感。
3. 老师课堂列表改成大封面内容平台样式：突出封面、标题、类型、权限、讲师和主行动。
4. 系列展开后的课件列表更清晰，能快速进入播放/购买流程。
5. 课件详情页与列表视觉统一，封面、播放区、权限提示和进度区层级更清楚。
6. 保持当前接口、路由、数据结构和后台能力不变。

## 设计原则

- **内容优先:** 大封面 + 明确标题 + 精简辅助信息，减少小字号拥挤信息。
- **入口明确:** 首页独立课堂 spotlight 卡片，位于 hero 后、功能宫格前。
- **现有风格延续:** 保留当前蓝紫首页、绿色学习中心视觉基因，课堂页使用深青绿色 + 暖橙 CTA。
- **播放感:** 通过播放按钮、媒体类型 pill、封面暗层和底部 CTA 建立“可以点开学习”的感知。
- **移动端可用:** 主按钮维持 88rpx 以上触控高度，列表卡片单列纵向，封面比例按后端配置展示。
- **渐进增强:** 图片加载失败继续显示同等比例占位；接口失败保留现有错误/重试状态。

## 页面方案

### 首页

在 hero 下方加入 `classroom-spotlight`：

- 文案：`老师课堂 · 视频 / 音频课件`、`老师以往开课内容，按系列沉淀成可反复学习的课件。`
- 行动：`进入老师课堂`
- 视觉：深色媒体卡片，左侧文字，右侧抽象播放器封面，使用 CSS 结构图形，不引入新图片依赖。
- 路由：`/pages/classroom/classroom?tab=series`

### 学一学页

保留现有老师课堂精选区，但改成更像“精选内容卡”：

- 顶部增加深色推荐 banner，与课堂页一致。
- 精选项使用稍大的封面、类型/系列标识、标题和“去查看”暗示。
- 空状态继续展示进入课堂按钮。

### 老师课堂列表页

采用内容平台单列大卡：

- 卡片纵向布局，顶部为全宽封面，封面上叠加类型/权限标签和播放按钮。
- 标题与简介在下方，底部显示讲师、时长/系列信息和主 CTA。
- 系列 tab 中点击卡片展开课件，选中态用边框和柔和阴影提示。
- 系列展开面板使用轻量章节列表，编号、类型和行动保持可扫读。

### 课件详情页

- 头部封面区域改为大封面 + 暗层信息，与列表一致。
- 播放区域使用统一 `player-panel` 视觉，音频播放器保留但更像播放卡。
- 进度、权限、购买状态继续沿用现有逻辑，仅做层级和间距优化。

## 非目标

- 不修改后台管理代码。
- 不修改课堂接口字段与购买/进度逻辑。
- 不引入新图标库、字体或远程静态资源。
- 不改变首页轮播图、测试、关系合盘、档案等既有入口行为。

## 验收

- 首页能直接看到“老师课堂”强入口。
- 从首页入口进入课堂系列 tab。
- 学一学页仍能看到老师课堂精选区，并能进入课堂。
- 课堂列表卡片为大封面内容平台样式。
- 详情页封面和播放器视觉与列表一致。
- `npm run test:config` 通过。
- `npm run build:mp-weixin` 通过，并产出 `dist/build/mp-weixin`。
